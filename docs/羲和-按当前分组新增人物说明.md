# 羲和按当前分组新增人物说明

当前版本支持在分组筛选状态下新增人物时，自动带入当前分组。

## 触发场景

在“重要的人”页面筛选某个分组后，点击：

- 右上角新增按钮；
- 空状态里的“新增人物”。

## 当前能力

如果当前正在查看“设计院”分组，打开新增生日表单时：

- “设计院”会默认选中；
- 用户仍可继续追加其他分组；
- 保存后人物会归入所选分组。

如果当前查看的是“全部”，则沿用默认分组。

## 产品价值

用户整理某个分组时，可以连续新增人物，不必每次重复选择同一个分组。

## 后续计划

- 从分组管理弹层中直接新增该分组人物；
- 空分组状态下进一步强化“新增到当前分组”的提示。
