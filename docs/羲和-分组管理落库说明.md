# 羲和分组管理落库说明

当前版本已将“分组管理”从本地原型状态升级为数据库持久化。

## 页面入口

“重要的人”页面顶部的分组栏，点击“+ 分组”进入管理弹层。

## 当前能力

支持：

- 新增分组；
- 重命名分组；
- 删除分组。

## 删除规则

删除分组只会解除人物与该分组的关联，不会删除人物资料。

如果人物没有任何分组，列表中会显示为“未分组”。

## 后端接口

- `GET /api/groups`：获取当前账号分组；
- `POST /api/groups`：新增分组；
- `PATCH /api/groups/:id`：重命名分组；
- `DELETE /api/groups/:id`：删除分组并解除关联。

## 安全边界

所有分组接口都限定在当前登录账号下，不能读取或修改其他账号的数据。

## 后续计划

- 支持分组排序；
- 支持分组颜色；
- 支持把未分组人物批量归类；
- 支持在编辑人物时从真实分组列表选择。
