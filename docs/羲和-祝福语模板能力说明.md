# 羲和祝福语模板能力说明

当前版本支持本地祝福语生成，不接入外部 AI 服务。

## 页面入口

- 首页“今天生日”卡片中的“写祝福”；
- 人物详情页中的“写祝福”。

## 当前能力

祝福语会结合：

- 人物姓名；
- 关系类型；
- 备注中的部分信息；
- 选择的语气。

当前支持四种语气：

- 温暖；
- 轻松；
- 正式；
- 诗意。

点击“复制并记录关怀”后：

1. 将祝福语复制到剪贴板；
2. 写入一条“写祝福”关怀记录；
3. 可在人物详情的关怀时间线中查看。

## 隐私说明

当前祝福语生成完全在浏览器本地完成，不调用外部模型，不上传人物备注。
