# 羲和数据导出与备份说明

当前支持 JSON 导出、本地备份、CSV 表格导出、JSON 备份恢复预检和确认恢复。

## 页面入口

在“我的”页可以进行：

1. “导出 JSON 备份”：浏览器下载一份 JSON 文件，同时服务端在本地生成一份备份文件；
2. “导出 CSV 表格”：下载人物生日表，可用 Excel/WPS 打开；
3. “预检 JSON 备份”：选择一份羲和 JSON 备份，先校验文件格式与数据数量；
4. 预检通过后可二次确认“追加恢复”，系统会跳过疑似重复人物，不覆盖、不删除现有数据。

## 导出内容

JSON 文件包含：

- 用户 profile；
- 人物资料；
- 生日资料；
- 分组；
- 人物与分组关系；
- 提醒规则；
- 最近提醒任务；
- 关怀记录。

## 接口

- `GET /api/export/json`：下载 JSON 导出文件；
- `GET /api/export/people.csv`：下载人物生日 CSV 表格；
- `POST /api/backups/json`：生成本地备份文件。
- `POST /api/import/json/preview`：预检 JSON 备份文件，返回可识别的数据数量和提示信息。
- `POST /api/import/json/restore`：确认后追加恢复 JSON 备份，跳过疑似重复数据。

## JSON 备份恢复预检

预检会检查：

- 文件是否为羲和 JSON 备份；
- `schemaVersion` 是否为当前支持版本；
- 人物、生日、分组、提醒规则、提醒任务、关怀记录等数据数量；
- 备份来源账号与当前账号是否不同；
- 是否存在已归档人物或明显缺失的生日记录。

预检阶段不会执行任何数据库写入，也不会覆盖现有数据。

## JSON 备份确认恢复

当前恢复策略为“追加恢复 + 去重保护”：

- 不执行覆盖恢复；
- 不删除当前账号已有数据；
- 按“姓名 + 历法 + 月 + 日 + 是否闰月”判断疑似重复人物；
- 分组按名称去重；
- 关怀记录按人物、动作、内容、完成时间去重；
- 旧备份里的提醒任务不会直接恢复，避免过期任务或去重键冲突，恢复后可在页面中重新刷新提醒内容。

恢复接口在一个数据库事务内执行；如果过程中出错，会整体回滚。

## CSV 导出字段

CSV 文件可用 Excel/WPS 打开，已包含 UTF-8 BOM 以降低中文乱码概率。

字段包括：

- 姓名
- 关系
- 主分组
- 全部分组
- 历法
- 出生年份
- 生日月
- 生日日
- 是否闰月
- 备注
- 创建时间

其中“全部分组”会用中文顿号 `、` 连接一个人物的多个分组，例如：

```text
同事、设计院、篮球
```

“主分组”为全部分组中的第一个分组，便于在 Excel/WPS 中快速筛选。

## 本地备份目录

默认位置：

```text
/Users/tyrion/Documents/员工关怀-生日提醒/prototype/.local/backups
```

`.local` 目录不会同步到 Desktop 主目录，也不会进入代码仓库。
