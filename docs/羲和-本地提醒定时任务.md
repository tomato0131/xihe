# 羲和本地提醒定时任务

本地阶段建议用 macOS LaunchAgent 每天 09:00 调用一次羲和提醒脚本。

## 手动执行

在 `prototype` 目录运行：

```bash
npm run reminders:daily
```

这条命令会完成两件事：

1. 生成未来三天生日提醒任务；
2. 执行已经到期的提醒任务。

## 安装本地定时任务

```bash
cd /Users/tyrion/Documents/员工关怀-生日提醒/prototype
bash scripts/install-local-scheduler.sh
```

安装后每天 09:00 运行一次。

日志位置：

```text
/Users/tyrion/Documents/员工关怀-生日提醒/prototype/.local/logs/daily-reminders.out.log
/Users/tyrion/Documents/员工关怀-生日提醒/prototype/.local/logs/daily-reminders.err.log
```

## 卸载本地定时任务

```bash
cd /Users/tyrion/Documents/员工关怀-生日提醒/prototype
bash scripts/uninstall-local-scheduler.sh
```

## 注意

- `.env.local` 只保存在本机，不同步到主目录。
- 企业微信 webhook 属于密钥，不要写入代码、文档或截图。
- 后续服务器部署时，应改用 systemd timer 或 cron，并把程序与日志放在 `/data/xihe` 下。
