# 羲和人物多分组能力说明

当前版本支持一个人物归属多个分组。

## 页面入口

- 新增生日表单；
- 编辑人物表单；
- “重要的人”列表筛选。

## 当前能力

- 新增/编辑人物时，可同时选择多个已有分组；
- 可在人物表单中输入并添加新分组；
- 保存后新分组会自动落库；
- 人物列表会展示多个分组；
- 点击任一分组筛选时，属于该分组的人都会出现。

## 兼容设计

系统仍保留 `group` 作为主分组，用于兼容已有数据和旧界面；新增的 `groups` 数组表示全部分组。

## 后续计划

- 支持拖拽调整主分组顺序；
- 在人物详情页以标签形式展示多分组；
- 在导出 CSV 中更清晰地展示多分组；
- 支持批量给人物追加分组。
