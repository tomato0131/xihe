# 羲和关怀建议清单说明

当前版本在首页提供“关怀建议”，把生日提醒进一步转化为可执行的小行动。

## 页面入口

首页底部“关怀建议”区域。

## 生成逻辑

系统会优先选择：

1. 今天生日的人；
2. 未来三天内最近生日的人。

围绕该人物生成三类建议：

- 写一句生日祝福；
- 找个合适时间联系 TA；
- 确认今年的小心意。

如果当前没有临近生日，则提示先新增重要的人。

## 行为说明

- 点击“写一句生日祝福”：进入祝福语模板面板；
- 点击“联系 TA”：写入一条“联系”关怀记录；
- 点击“确认小心意”：写入一条“备礼物”关怀记录；
- 已完成的建议会在当前页面状态中标记。

## 产品定位

这不是任务管理器，而是把“生日提醒”变成更温柔、更容易执行的关系关怀动作。

## 后续计划

- 根据关系类型生成更细分的建议；
- 根据备注内容生成个性化建议；
- 支持用户自定义建议模板；
- 将已完成状态与关怀记录做更强关联。
