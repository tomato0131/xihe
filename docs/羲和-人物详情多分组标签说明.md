# 羲和人物详情多分组标签说明

当前版本已在人物详情页展示多分组标签。

## 页面入口

点击“重要的人”列表中的任意人物，进入人物详情页。

## 当前展示规则

- 人物姓名上方展示关系；
- 人物姓名下方展示全部分组标签；
- 如果人物只有一个分组，则展示一个标签；
- 如果是旧数据，仅有主分组，也会兼容展示主分组。

## 产品价值

多分组标签能帮助用户更快理解一个人的关系场景，例如：

```text
同事 / 设计院 / 篮球
```

这比只显示一个主分组更贴近真实人际关系。

## 后续计划

- 点击详情页分组标签后跳转到该分组筛选；
- 支持主分组排序；
- 支持分组颜色在标签中体现。
