# 羲和｜阶段 B 当前能力清单

更新时间：2026-07-09  
阶段定位：本地可运行原型已具备“生日提醒 + 关系关怀 + 数据备份”的核心闭环，文件导入暂缓，后续可进入部署、后台管理和真实通知增强阶段。

## 1. 当前产品定位

羲和是一款面向移动端体验的智能生日管家。它不只记录生日，也围绕“重要的人”形成提醒、关怀建议、关系记忆与数据备份能力。

当前产品体验重点：

- 柔和东方极简视觉，贴合“羲和 / 日光 / 时序”的产品气质。
- 首页以“今日”“未来三日”“久未关怀”“今日关怀清单”为核心。
- 人物页以生日、分组、搜索、关怀状态筛选为核心。
- 详情页从单纯生日资料升级为“关系记忆页”。
- 数据以本地 PostgreSQL/API 为主，支持 JSON/CSV 导出备份。

## 2. 已完成核心能力

### 2.1 账号与本地数据

- 本地登录页与 demo 账号流程。
- 本地 API 服务。
- 本地 PostgreSQL 数据库。
- 人物、生日、分组、提醒任务、关怀记录等核心数据落库。
- 基础账号隔离与 API 冒烟测试。

### 2.2 人物生日管理

- 手动新增人物。
- 编辑人物资料。
- 归档人物。
- 支持公历 / 农历生日。
- 支持闰月标记。
- 支持出生年份未知，只记录月日。
- 自动计算下一次生日。
- 自动生成“今天 / 明天 / 后天 / 还剩 N 天”等相对时间。

### 2.3 分组能力

- 真实数据库分组列表。
- 新建分组。
- 改名分组。
- 删除分组。
- 删除分组只解除关联，不删除人物。
- 人物支持多分组。
- 新增人物时可按当前筛选分组自动带入。
- 详情页分组标签可点击跳转到对应分组筛选。

### 2.4 搜索与筛选

- 搜索姓名。
- 搜索关系。
- 搜索备注。
- 搜索分组。
- 搜索生日关键词，例如：
  - `5月`
  - `5月18日`
  - `05-18`
  - `0518`
- 搜索结果支持高亮。
- 备注命中时展示备注摘要。
- 生日命中时生日日期块高亮。
- 支持月份快捷筛选：
  - 全部生日
  - 本月
  - 下月
  - 未来30天
  - 1月～12月
- 支持关怀状态筛选：
  - 全部关怀
  - 久未关怀
  - 暂无记录
  - 30天内

### 2.5 首页体验

- 今日生日 Hero。
- 未来三日生日提醒。
- 页面内“日光提醒”中心。
- 最近关怀记录。
- 久未关怀提醒模块。
- 久未关怀支持一键记录“联系”。
- 久未关怀支持“查看全部”跳转到人物列表并自动筛选。
- 今日关怀清单：
  - 待处理提醒
  - 临近生日建议
  - 久未关怀联系人
- 今日关怀清单支持任务类型标签：
  - 提醒
  - 生日
  - 久未关怀
- 今日关怀清单支持完成态：
  - 打勾
  - 显示“已完成”
  - 空状态：“今日清单已清爽”

### 2.6 人物详情页

- 展示人物头像、关系、生日、下一次生日。
- 展示多分组标签。
- 快捷动作：
  - 写祝福
  - 联系 TA
  - 备礼物
- 关怀节奏模块：
  - 生日倒计时
  - 最近一次关怀
  - 智能建议文案
- 手动填写关怀记录：
  - 普通关怀
  - 联系
  - 礼物
  - 祝福
- 关怀记录时间线。
- 备注 / 关于 TA。

### 2.7 祝福与关怀

- 祝福语模板能力。
- 按不同语气生成祝福：
  - 温暖
  - 轻松
  - 正式
  - 诗意
- 复制祝福并保存为关怀记录。
- 首页和详情页的快捷关怀动作会写入关怀记录。

### 2.8 提醒能力

- 页面内提醒中心。
- 打开页面自动检查未来三天生日。
- 支持提醒任务生成。
- 支持待提醒 / 已提醒 / 已关怀等状态。
- 支持执行到期提醒。
- 企业微信 webhook 能力已做技术验证，但按当前产品策略暂时搁置真实外部推送，优先页面内提醒。

### 2.9 岁历页面

- 年度月份网格。
- 当前月份标记。
- 每月生日数量统计。
- 点击月份后在岁历页内预览该月人物。
- 预览区支持“查看全部”，跳转人物列表并自动筛选该月。
- 年度关怀概览：
  - 已记录人数
  - 本月生日人数
  - 未来30天生日人数

### 2.10 数据导出与备份

- JSON 完整数据导出。
- JSON 本地备份。
- JSON 备份预检。
- JSON 追加恢复：
  - 不覆盖现有数据
  - 不删除现有数据
  - 跳过疑似重复人物
- CSV 人物生日表导出。
- CSV 支持多分组字段：
  - 主分组
  - 全部分组

## 3. 当前暂缓能力

- 文件导入功能暂缓。
- 外部微信 / 企业微信真实推送暂缓。
- 后台管理页面暂缓。
- 服务器部署暂缓，当前优先本地部署与本地 PostgreSQL。

## 4. 已验证情况

阶段 B 期间每次重要改动后均执行：

- `npm run build`
- `npm run test:api`
- webhook 密钥外泄检查
- 同步到 Desktop 主项目目录
- 同步到 `羲和-prototype`

当前本地原型入口：

- 前端：`http://127.0.0.1:5175/`
- API：`http://127.0.0.1:8787/`
- 本地 PostgreSQL：Docker 容器 `xihe-postgres-local`

## 5. 当前产品闭环

当前羲和已经形成如下闭环：

1. 记录重要的人。
2. 设置生日、分组、备注。
3. 首页自动浮现生日与关怀任务。
4. 人物列表支持搜索、分组、生日、关怀状态筛选。
5. 详情页记录祝福、联系、礼物与关系记忆。
6. 岁历页按年度时间查看生日分布。
7. 数据支持 JSON/CSV 导出备份。

## 6. 建议下一阶段

### 阶段 C：从本地原型走向可部署产品

建议优先顺序：

1. 明确部署架构：
   - 本地继续开发
   - 虚拟机部署 PostgreSQL/API
   - 前端静态部署或统一容器部署
2. 增加生产环境配置规范：
   - `.env` 示例
   - 数据库初始化脚本
   - 备份目录策略
   - 日志目录策略
3. 设计后台管理页面：
   - 数据备份管理
   - 通知通道管理
   - 用户 / 账号管理
   - 导入任务管理
4. 恢复文件导入能力：
   - CSV / XLSX 模板
   - 字段映射
   - 重复数据预检
5. 通知通道产品化：
   - 页面内提醒继续保留
   - 企业微信 webhook 配置页
   - 发送记录与失败重试
6. PWA / 移动端增强：
   - 移动端安装
   - 离线提示
   - 首屏加载优化

## 7. 备注

当前阶段的重点不是堆更多页面，而是已经把“生日提醒”扩展成“关系关怀”的产品骨架。后续如果进入部署阶段，应优先保证数据安全、备份恢复、配置隔离和通知可靠性。
