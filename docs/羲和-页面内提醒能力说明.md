# 羲和页面内提醒能力说明

羲和的提醒能力分为两层：

1. 页面内提醒：用户打开羲和后，首页会自动检查未来三天生日，并在“日光提醒”卡片里展示待提醒内容。
2. 通道发送：用户点击“执行到期提醒”后，羲和会通过已配置通道发送，例如站内提醒、企业微信群机器人。

当前阶段不依赖电脑终端弹窗，也不要求用户查看命令行输出。

## 首页提醒中心

首页新增“日光提醒”模块：

- 自动生成未来三天提醒任务；
- 展示待提醒人物、提醒时间、提醒通道、提醒状态；
- 支持手动刷新；
- 支持一键执行到期提醒。
- 支持单条提醒处理：
  - “稍后”：把提醒重新排到稍后时间；
  - “已关怀”：记录一条关怀完成记录，并停止该提醒继续出现为待办。

## 我的页面

“我的”页会展示当前待提醒数量，并提供：

- 刷新提醒内容；
- 执行到期提醒；
- 通知通道检查。

## 后端接口

- `GET /api/reminders/jobs`：读取最近 30 天提醒任务；
- `POST /api/reminders/generate`：生成未来三天提醒任务；
- `POST /api/reminders/run`：执行到期提醒任务。
- `PATCH /api/reminders/jobs/:id`：处理单条提醒，支持 `snooze` 和 `complete`。

## 后续增强

- 增加页面内通知铃铛红点；
- 增加提醒历史页面；
- 支持 PWA 后台推送或移动端系统通知。

## 关怀记录

当前已支持把页面内行为沉淀为关怀记录：

- 人物详情页展示该人物最近关怀时间线；
- 首页展示最近关怀摘要；
- “写祝福 / 联系TA / 备礼物”会生成对应关怀记录；
- 提醒卡片点击“已关怀”会生成完成记录。

接口：

- `GET /api/care-records`：读取最近关怀记录；
- `GET /api/people/:id/care-records`：读取某个人的关怀时间线；
- `POST /api/care-records`：新增关怀记录。
