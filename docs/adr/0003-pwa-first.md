# ADR-0003：移动端优先 PWA，微信后置

## 状态

建议接受

## 背景

产品必须支持移动端，现有原型已采用 React。微信通知和小程序能力受主体、模板、授权频次及审核规则约束，无法在资质不明确时作为首版基础能力。

## 决策

首版交付响应式 PWA，复用现有 React 原型，提供桌面安装、系统通知和邮件兜底。微信通过通知适配层在二阶段独立验证。

## 影响

优势是跨平台交付快、现有代码可复用、不受应用商店审核阻塞；不足是 iOS Web Push 存在系统版本与安装条件限制，微信内浏览器能力也有限。若个人用户主要来自微信，可在验证后增加小程序端。

## 备选方案

- 微信小程序优先：触达生态更好，但平台绑定强，且不覆盖所有移动端场景。
- 原生 iOS/Android：体验和通知能力最好，但首版成本过高。
- uni-app/Taro 多端：适合第二阶段多端统一，但当前迁移会延迟 MVP。
