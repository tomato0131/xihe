# ADR-0004：提醒使用持久化任务和幂等发送

## 状态

建议接受

## 背景

生日提醒是羲和最关键的承诺。只依赖客户端定时器或即时扫描会受到应用未打开、浏览器休眠、网络中断和函数重复执行影响。

## 决策

提前生成 `notification_jobs`，每条任务保存计划时间、渠道、状态、尝试次数和唯一去重键。发送器周期拉取到期任务，成功落库，失败最多重试 3 次。

## 影响

优势是可追踪、可补偿、可防重复，并能支持通知健康检查；不足是增加任务表维护和清理逻辑。MVP 不引入独立消息队列，任务量增长后再评估队列服务。

## 备选方案

- 每日即算即发：实现简单，但失败后难追踪、难补偿。
- 客户端本地通知：无法覆盖未安装或长期未打开的用户。
- Kafka/RabbitMQ：当前规模下运维成本不合理。
