# 羲和人物列表空状态引导说明

当前版本在“重要的人”页面增加了空状态引导。

## 触发场景

- 当前账号还没有人物；
- 当前分组下没有人物；
- 搜索关键词没有匹配结果。

## 当前能力

根据不同场景展示不同提示：

- 全部为空：提示先新增一位重要的人；
- 分组为空：提示该分组暂无人物，并提供“查看全部”和“新增人物”；
- 搜索为空：提示换关键词，并提供“清空搜索”。

## 产品价值

空状态不再只是“没有内容”，而是给用户下一步动作，降低第一次使用和整理分组时的困惑。

## 后续计划

- 分组为空时，新增人物默认带入当前分组；
- 搜索为空时支持按备注/关系增强搜索；
- 批量导入入口也可放入空状态。
